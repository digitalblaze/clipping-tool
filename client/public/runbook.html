🎯 SAT Moments — Tester Runbook

Zoom class → three published clips

This walks through one full pass of the pipeline: what to type into the SAT Classes sheet, which menu items to run and in what order, and where to check the result. Takes about ten minutes once a Zoom recording is ready.

Open the clip page → Open the sheet
01 — BEFORE YOU RUN ANYTHING

Add a row to the sheet

Pick a blank row. Only column A is required — everything else is either optional or filled in automatically by the pipeline.

A
Zoom Meeting ID. The plain meeting ID works for whatever recording is most recent. For one specific past class, use that recording's exact UUID instead — find it in the Zoom web portal under Recordings and Transcripts, copy the class's link, and the ID in that link is the UUID.
Required
B
Class Title. Leave blank to use Zoom's own topic for the recording.
Optional
C
Class Date. Leave blank to use the recording's actual start time.
Optional
D–R
Everything else. Status, transcript, moments, clip links — all written by the pipeline as it runs. Don't pre-fill any of it.
Leave blank
02 — RUN THESE, IN ORDER

From the 🎯 SAT Moments menu

Run one, wait for the Status column to reach the value shown, then run the next. Don't skip ahead.

1
1. Pull Zoom captions + source URL

Fetches the recording from Zoom and saves its transcript. Takes a few seconds.

Status becomes Assets Ready
2
2. Find top 3 viral moments (AI)

Reads the transcript and picks three clip-worthy moments. Takes 10–30 seconds.

Status becomes Moments Found
3
3. Send clip jobs to clip service

Hands the job to the clip service. This step itself is instant — the actual cutting happens afterward on its own. Give it a few minutes; don't run it again while you wait.

Status moves on its own: Clips: requested → Clips: processing → Clips: done
4
4. Ingest finished clips to Brightcove

Only run this once Status actually says Clips: done — running it earlier won't find anything to publish.

Status becomes Published, Brightcove IDs land in column Q
03 — SITUATIONAL TOOLS

Not part of the normal run

Below the divider in the same menu. Only reach for these when something specific calls for them.

🔄
Refresh expired Zoom source URLs
Only if a row's Zoom link has gone stale — more than about an hour since step 1 — and step 3 or 4 fails with an auth-looking error.
📅
Backfill missing dates + durations
A repair tool for older rows missing column C or H. Not needed on a freshly run row.
🧹
Clear stuck resume triggers
Only if a step seems stuck — it was interrupted partway and needs a clean restart.
04 — CHECK THE RESULT

On the clip page

Pick the class from the sidebar. Three tabs:

Clips

The three finished clips, playable, each with its hook and source timecode.

Transcript

The full class transcript, searchable, with the clipped ranges highlighted.

Full Recording

The whole class, with the three clip moments marked on the timeline.

● The page can take about 30 seconds to wake up on its first load after sitting idle — that's normal, not an error. Worth opening it once before showing anyone else.
05 — IF SOMETHING LOOKS WRONG

Quick checks before flagging it

  1. Check column R (Error) on that row — it's usually a plain-language explanation of what happened.
  2. No clips on the page yet? Confirm Status actually reached Clips: done, not just Clips: requested — step 3 finishes in the background.
  3. Still stuck? Send the row number and whatever column R says to Gregory.
